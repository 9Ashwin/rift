# Godot + Blender 游戏开发工作坊

把想做的游戏拆成一个能跑完的 3D 教学切片。这里先收集案例、GitHub 工具、教程和资产流程，再据此做一款原创小项目。

## 文档

- [游戏案例与资源地图](docs/research.md)：Steam 热度样本、Godot/Blender 教程、AI 编程与 3D 资产工具、X 上的公开线索。
- [原创教学项目 brief](docs/teaching-project.md)：一个单人、低多边形、短流程的 Godot 3D 垂直切片。

## 先走这条路

先用 GDQuest 的 Godot 3D 入门项目跑通引擎，再按 Blender → glTF/GLB → Godot 的官方资产导入流程做自己的模型。[12][25] 最后做一张小地图、一个巡逻敌人和一个完整的胜负循环。别第一天就开多人联机和程序生成，那个范围能把人活活埋了。

## 研究口径

- 资料快照日期：2026-10-10。GitHub Stars 和推送时间会变，数字只表示这次检索时的状态。
- SteamDB 数字是历史峰值与发生日期，不等于当前在线人数，也不是未来销量预测。
- X 只通过可索引公开页面取线索，不是全站趋势榜；不把搜索结果包装成“最火排名”。
- 第三方项目和素材继续受各自许可证约束。仓库不收集 API key、账户令牌或付费模型输出。
